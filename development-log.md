# School Event Registration Website – Development Log

## Week 1: Planning
I selected the School Event Registration Website as my project. I identified the target users, the main problem and the purpose of the website. I also prepared the website requirements and planned the main pages.

## Week 2: Design
I planned the Home, Events and Registration pages. I selected blue, white and light green as the main colours. I also planned the navigation and layout to make the website easy to use.

## Week 3: Website Development
I created the HTML pages using Notepad. I added navigation links and designed the website using CSS. I checked that the three pages opened successfully.

## Week 4: JavaScript Development
I added JavaScript features for event searching and category filtering. I also created registration form validation and a confirmation message. Registration information was saved using Local Storage.

## Week 5: Multimedia and Responsiveness
I added a school event image and video to the Home page. I included alternative text for the image and a video description. I tested the website on mobile view and checked keyboard navigation.

## Week 6: Testing and Final Improvements
I tested the website features and recorded 12 test cases. I used Lighthouse to check website quality and saved screenshots of the results. I uploaded my website files and development log to GitHub.

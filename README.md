# School-Event-Registration
A responsive school event registration website created for my Interaction Design assessment.
## Website Features

- Home page introducing the school events.
- Events page displaying Sports Day, Cultural Day and Science Exhibition.
- Search and category filtering for finding events.
- Registration form with input validation.
- Confirmation message after successful registration.
- Local Storage for saving registration information.
- Responsive design for desktop and mobile devices.
- School event image and video.

## Technologies Used

- HTML5 – Website structure.
- CSS3 – Website design and responsive layout.
- JavaScript – Interactive features and form validation.
- Local Storage – Saving registration information.
- GitHub – Storing project files and development progress.

## Project Purpose

This website was developed to help students view school events and register for activities easily.
